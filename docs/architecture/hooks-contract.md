# Catalogue des hooks — phase 0.0

La phase 0.0 n’enregistre encore aucun hook métier public. Les hooks futurs doivent être documentés avec nom, producteur, consommateur, priorité, raison et comportement de rollback. Les APIs CRUD WooCommerce sont obligatoires pour les commandes ; aucune fonction privée ou requête SQL directe ne doit être utilisée sans justification écrite.
